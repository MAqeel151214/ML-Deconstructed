# ML Deconstructed

ML Deconstructed is an open, dependency-ordered machine-learning curriculum. It focuses on the part often hidden by high-level APIs: how a model turns numbers into a prediction, how its objective is formed, and how the code follows from the mathematics.

## How to use this course

Each published lesson is self-contained, but the recommended order follows the table of contents. Start with Module 00 unless you are already comfortable with linear algebra, calculus, probability, NumPy arrays, and their shapes.

A lesson will tell you:

- what you should already know;
- what you will be able to do afterwards;
- the notation and assumptions it uses;
- how to reproduce its calculations and code; and
- where to read further.

## The learning standard

The curriculum uses deliberately small toy examples before scaling to realistic workflows. For important deterministic quantities, you will see the formula, the value of every symbol, the intermediate arithmetic, an interpretation, and an executable check.

This makes the material suitable for careful first learning, later revision, and debugging your own implementations.
